## 📌 Overview

**AZEEFIT** is a Gym Management Application built with the **MERN stack (MongoDB, Express, React, Node.js)** and styled using **Tailwind CSS**.  
It helps gym owners and trainers manage members, subscriptions, classes, and attendance efficiently.

---

## ✨ Features

- 🔑 **Authentication & Authorization** (JWT-based)  
- 🏋️‍♂️ **Member Management** – Add, update, and track members  
- 💳 **Subscription Plans** – Manage membership packages & billing  
- 📅 **Class Scheduling** – Trainers can create & manage workout sessions  
- 📊 **Dashboard** – View gym stats & insights  
- 🎨 **Responsive UI** with TailwindCSS  

---

## 🚀 Tech Stack

- **Frontend:** React, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT & bcrypt  
- **API Testing:** Postman
